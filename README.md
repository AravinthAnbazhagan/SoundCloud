# SoundCloud - Music Streaming Platform

## Project Overview

SoundCloud is a C++-based music streaming platform where users can listen to music and podcasts, create playlists, and subscribe. Providers can upload content such as music, podcasts, and advertisements. Admins oversee platform operations, manage users and providers.

The application demonstrates core object-oriented programming and data structures in C++ with integrated MySQL for database operations.

## Roles

- **Users**: End users who consume the content and manage playlists
- **Providers**: Upload music, podcasts, and advertisements
- **Admin**: Monitor all user and provider activities

## Technologies Used

- **Programming Language**: C++
- **Database**: MySQL

## Data Structures and Algorithms

Implemented splay trees, graphs, stacks, queues, BFS, and DFS.

## Database

- **Database Name**: `soundcloud`
- **Type**: Relational (MySQL)
- Tables include:
  - `users`, `artists`, `songs`, `user_history`, `user_playlists`, `user_languages`, `user_artists`, `user_genres`, etc.

## Important Note

Although the files are organized in folders in the GitHub repository for better understanding, the project must be run by placing **all `.h` and `.cpp` files in a single directory**, without any subfolders.
